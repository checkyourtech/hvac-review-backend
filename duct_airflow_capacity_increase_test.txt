HVAC SYSTEM REPLACEMENT PROPOSAL
Project: Sample Home E, whole conditioned home, single system.
Capacity increase: existing system 3 tons; proposed system 4 tons, with existing ducts reused.
The existing system is currently operating. No equipment failure is claimed.
The homeowner requested a proactive replacement during a planned remodel.
This is a voluntary planned upgrade, not a necessary repair or failure-driven replacement.
Replace the complete ducted HVAC system using existing supply and return ducts.
Proposed equipment: Example EX-C48 outdoor AC, Example EX-I48 indoor coil, and Example EX-F60 furnace.
Condenser: Example EX-C48, 208/230V single-phase, R-454B.
Coil: Example EX-I48, R-454B, with the factory-specified TXV listed on sheet E-17.
Furnace: Example EX-F60, with the blower configuration listed on sheet E-17.
Submitted manufacturer approved combination sheet E-17 lists EX-C48, EX-I48 and EX-F60 together as an approved matched combination with the specified metering device.
